# Pràctica de treball col·laboratiu amb Git

## Descripció

Projecte de pràctiques per treballar amb Git de manera col·laborativa.

## Col·laboradors

* mahe248-afk
* joma280-glitch

## Normes de treball

* Branca principal: `main`
* Branques de funcionalitat: `feature/nombre-funcionalitat`
* Els missatges de commit han de ser clars i descriptius.
* Cada Pull Request ha de ser revisat per un altre membre de l'equip abans de fer la integració a `main`.

## Funcionalitats desenvolupades

Les diferents branques afegiran aquí la informació corresponent a les modificacions realitzades, indicant el nom de la branca, una descripció dels canvis i la data i hora.

### Incorporació d'un nou col·laborador
* Autor: joma280-glitch
* Branca: 'feature/afegir-collaborador'
* Descripció: afegir joma280-glitch a la llista de col·laboradors
