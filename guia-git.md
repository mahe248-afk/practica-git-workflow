# Guia bàsica de Git



- 'git clone URL': clona un repositori.
- 'git status':mostra l'estat dels fitxers.
- 'git switch -c nom-branca': crea una branca i hi entra.
- 'git add fitxer': prepara els canvis per al commit.
- 'git commit -m "missatge"': guarda els canvis al historial local.
- 'git push -u origin nom-branca': puja la branca al repositori remot.
